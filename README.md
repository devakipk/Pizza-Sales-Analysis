# Pizza-Sales-Analysis
Pizza Sales Data Analysis using Python, Pandas, NumPy, Matplotlib, and Seaborn to explore sales data, perform data cleaning, detect outliers, and visualize insights for better business decision-making.


Pizza Sales Analysis Project 

Project Title

Pizza Sales Analysis Using Python

Description

This project focuses on analyzing pizza sales data using Python. The main objective is to understand pizza sales performance, identify best-selling and least-selling pizzas, analyze revenue trends, and explore customer ordering patterns through data analysis and visualization.

Project Objective

- Analyze pizza sales and revenue.
- Identify best-selling and least-selling pizzas.
- Understand category-wise and size-wise sales.
- Analyze monthly and daily revenue trends.
- Explore hourly order patterns.
- Generate meaningful business insights.

Dataset

- Pizza Sales Dataset
- Format: CSV

Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn

Features

- Data Loading and Exploration
- Data Cleaning
- Data Evaluation
- Category-wise Sales Analysis
- Size-wise Sales Analysis
- Top 5 Best-Selling Pizzas
- Least 5 Selling Pizzas
- Top 5 Pizzas by Revenue
- Monthly Revenue Analysis
- Daily Revenue Analysis
- Hourly Orders Analysis
- Category and Size-wise Quantity Analysis
- Outlier Detection
- Data Visualization

Visualizations

- Pie Chart
- Bar Chart
- Line Chart
- Grouped Bar Chart

Key Insights

- Analyzed sales and revenue across pizza categories.
- Identified the top 5 and least 5 selling pizzas.
- Compared pizza sales based on size.
- Analyzed monthly revenue distribution.
- Studied daily revenue trends.
- Identified order patterns across different hours.

How to Run

1. Download the project notebook.
2. Open it in Google Colab.
3. Upload the "pizza_sales.csv" dataset.
4. Run all notebook cells.
5. Explore the analysis results and visualizations.

Conclusion

This project helped in understanding pizza sales data through Exploratory Data Analysis (EDA). It provided insights into sales performance, revenue trends, popular pizza products, and ordering patterns using Python libraries.
